# 작가 페이지 디자인 적용

## 선택 방법

작가: 대시보드 → 프로필 → 페이지 구성.
관리자: 작가 관리 → 해당 작가 편집 → 페이지 구성.

1. 프링 예시 이미지에서 ‘전체 시안 보기’로 확대합니다.
2. 원하는 디자인의 ‘이 디자인 선택’을 누릅니다.
3. ‘초안 미리보기’로 자신의 실제 내용이 배치된 모습을 확인합니다.
4. ‘변경사항 저장’을 누르면 선택한 디자인이 저장됩니다.

디자인 전환은 입력한 작품·CV·작가노트·선택 섹션·섹션 순서를 지우지 않습니다.

## 세 가지 구조

- White Cube: 첫 번째 유효한 작품을 크게 보여주고, 작품 아래에 작가 정보를 배치합니다. 작품이 없으면 커버 이미지를 사용합니다. 대표작 두 점과 전체 아카이브 보기를 제공합니다.
- Journal: 작가노트의 짧은 첫 줄(100자 이하)을 오프닝 문장으로 사용합니다. 소개와 이미지의 비대칭 구성, 두 대표작, 검은 배경의 작가노트·작품 이미지가 특징입니다.
- Archive: 큰 커버 없이 작가 정보를 간결하게 배치합니다. 작품 여섯 점을 3열로 표시하고 매체·제작 연도 필터를 제공합니다. 소개 다음에 CV가 오는 경우 두 항목을 나란히 보여줍니다.

모바일에서는 읽기 쉬운 단일 열로 재배치합니다. 원본 작품 비율과 색을 유지하며, 줄바꿈도 유지합니다.

## 공통 / 선택

공통 편집 항목: 기본 정보, 작품, 소개·작가노트, CV, 문의 설정.
선택 표시 항목: 예정 전시, 작업 아카이브, 영감의 서재.

내용이 없는 소개·CV·선택 섹션은 공개 페이지와 메뉴에서 숨깁니다. 문의는 협업 또는 문의 목적을 활성화한 경우에만 표시합니다. 지난 전시는 CV에 유지합니다.

프링 이미지는 디자인 선택을 위한 예시일 뿐, 실제 작가 등록이나 홈페이지 작품 목록에 추가되지 않습니다. 시안 속 버추얼 전시 블록은 실제 연동이 마련될 때 별도로 연결해야 합니다.
