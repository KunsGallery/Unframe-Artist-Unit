# 전체 UX 개선 반영 내역

2026-09-30. 보고서의 확정 오류와 기존 기능의 UX를 수정했다. 운영 데이터 삭제, 신규 테스트 계정 생성, 권한 확대, Git 푸시 및 운영 배포는 하지 않았다.

## 구현

- 모바일 작가 히어로를 한 열로 고정. 작가 전용 셸로 중복 플랫폼 헤더·푸터·도움 버튼 제거. 내용 없는 CV/전시/과정/영감/소개는 메뉴와 본문에서 함께 생략.
- 홈페이지의 실제 7개 섹션을 순서·숨김 제어와 연결. 오래된 섹션 ID를 정규화하고 중복된 무효 제어 제거. 공간 아카이브 본문도 서버 저장 가능한 편집 키로 등록.
- 삭제된 데모 상세 미리보기 제거. 실제 작가 선택은 관리자 작가 관리로 연결. 상세용 공통 사이트 편집 항목은 선택 목록에서 제거.
- 신규 작가 기본 검수 상태를 pending으로 설정. 프로필 저장에서 undefined를 재귀 제거하되 Firestore Timestamp/FieldValue를 유지.
- 프로필 항목 바로가기, 고정 저장바, 저장 상태, 이탈 경고, 저장 전 초안 미리보기 추가. 저장 중 추가 입력은 저장 완료 상태로 잘못 표시하지 않음.
- CV 입력기를 한 곳으로 통합. 컬렉터 등 비작가의 작가 전용 필드·빌더·해금·뷰잉룸 메뉴를 숨김.
- 관리자 업무 메뉴 추가, 대형 제목 압축, 알림 수신자·권한 대상에 회원 이름/이메일 검색 및 선택 UI 제공. 실제 계정을 바꾸는 테스트 도구를 접고 실행 확인 추가.
- 비공개 링크 전시 조회 실패 시 편집 폼을 열지 않고 한국어 오류·재시도 안내. 공개 R2 이미지의 유출 방지 한계는 유지.
- 빈 공개 아카이브와 검색 실패 구분, 아티스트가 없으면 랜덤 버튼 숨김. 목록의 자기 자신으로 돌아가는 링크를 섹션 이동으로 교체.
- 공개 프로필 실시간 구독을 공유하고 24개 단위 페이지네이션 추가. 작품 검색은 불러온 작가 범위임을 안내. 최신순이 아니었던 홈 제목은 중립적인 'U.A.U 아티스트'로 수정.
- 작품 원본은 유지하고 새 업로드부터 1600px/640px WebP 파생본을 생성. 실제 이미지 너비를 저장해 반응형 이미지 선택 적용. 기존 원본 데이터는 변경하지 않음.
- 이미지 업로더의 한국어 안내, 교체 버튼 접근성 이름, 삭제 버튼 터치 영역 개선.
- 비밀번호 재설정 안내 추가, 미지원 소셜 로그인 선택지 제거. 추천 주기 번역 및 실제 예약 발송이 아닌 선호 저장임을 표시.
- 작가/작품/갤러리/전시 상세의 공개 데이터 기반 메타데이터·OG·정규 URL 추가. 비공개/조회 실패 상세는 noindex. 서버 조회는 익명 Firestore 권한을 따름.
- 공유 3D 전시가 아직 별도 로컬 시제품임을 프로필/가입/공개 공간 안내에 명시. 실제 준비도를 관리자 100%로 덮어쓰지 않음. 정적 리캡의 주요 메뉴 노출 축소.

## 검증

- TypeScript 검사 통과(최종 빌드에 타입 검사도 포함).
- 최종 `npm run build` 성공. 기존 CSS start/end 값 호환성 경고가 남지만 오류는 없다. `node --test tests/ux-data.test.cjs`의 직렬화/빈 섹션 검사 2개도 통과.
- Firestore 에뮬레이터 권한 테스트 6개 통과. 소유자 목록 조회와 슈퍼관리자 목록 조회 성공 사례를 추가. 타인의 조회·쓰기 및 닫힌 룸의 비회원 읽기는 거부.
- Java 21 기존 설치 사용. 에뮬레이터 한국어 번역 리소스 오류를 피해 영어 로케일로 실행. 운영 DB가 아닌 demo 프로젝트 사용.
- 실제 브라우저에서 390px 작가 레이아웃을 긴 한·영 이름과 커버로 검사: 한 열, 가로 넘침 없음, 헤더 1개. 임시 로컬 fixture는 검사 후 제거.
- 1440px 아티스트 목록의 빈 상태, 참여 안내, 섹션 이동 링크 확인. 브라우저 오류 로그 없음.
- Impeccable 안티패턴 검사 대상에서 검출 0건. 모든 접근성이나 디자인 품질을 보증하는 결과는 아님.

## 완료로 주장하지 않는 범위 / 후속 검증

1. 현재 로컬 검수 브라우저는 미로그인. 운영자 로그인이 필요하며 실제 저장→새로고침, 홈 숨김/순서 발행→새 세션 확인, 업로드 성공을 아직 수행하지 않았다.
2. 운영 뷰잉룸 권한 오류의 근본 원인은 확정하지 않았다. 로컬 규칙과 역할 테스트는 통과했지만 운영 배포 규칙·IAM/프로젝트를 대조해야 한다. 권한을 열어 우회하지 않았다.
3. 3D 전시의 작가 소유권·공유 저장소·공개 링크·해금 운영 연결은 아직 미구현. 안내를 정확히 수정한 것이며 프로토타입을 운영 기능으로 바꾼 것은 아니다.
4. 비밀번호/만료 초대·비공개 버킷은 새 보안 설계와 운영 선택이 필요하다. 현재 링크 전시는 비밀번호/DRM으로 보호되지 않는다.
5. 작가 계정 인계, 갤러리·전시 및 관리자 목록의 전체 페이지네이션, 별도 목록 요약 컬렉션, 자동 리캡/오픈콜 관리, 예약 추천 발송은 별도 구현이 필요하다.
6. 기존 이미지 일괄 파생본 생성은 하지 않았다. 새 작품 업로드에만 적용한다. 실기기 성능, Lighthouse, 실제 소셜 크롤러와 공개 작품 데이터가 많은 경우는 추가 측정이 필요하다.

## 직원 로그인 후 체크리스트

- [ ] `/admin` 메뉴에서 작가 관리·승인·사이트 편집에 직접 진입할 수 있다.
- [ ] 관리자 작가 등록 초안을 저장할 수 있고 undefined 오류가 없다.
- [ ] 작가 편집에서 작품 아래까지 내려가도 고정 저장바를 사용할 수 있다.
- [ ] 저장 전 초안 미리보기에 줄바꿈·커버·작품·섹션 선택이 나타난다.
- [ ] 프로필 저장 후 새로고침해 변경이 유지된다. 공개 여부는 의도한 상태로만 변경한다.
- [ ] 이미지 업로드 후 표시용 WebP URL이 저장되고 작품 확대에는 원본이 사용된다.
- [ ] 홈 섹션 순서/숨김을 미리보기에서 검증한다. 운영 발행은 검토된 변경만 한다.
- [ ] 일반 작가, 컬렉터, 비회원 각각의 메뉴/공개 범위를 확인한다.
- [ ] 운영 뷰잉룸 조회 오류 재현 여부와 적용된 Firestore 규칙을 확인한다.
