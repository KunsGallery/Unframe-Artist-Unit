# 아임웹 멤버십 상품 정보

U.A.U 멤버십 1년권을 아임웹 UNFRAME 스토어에 올릴 때 쓰는 정보입니다.
상품은 두 개입니다. 자동 연동을 붙일 때 상품으로 멤버와 창립 멤버를 구분합니다.

대표 이미지 (1200 × 1200 px, PNG):

- 멤버: `docs/operations/imweb/uau-member-1year.png`
- 창립 멤버: `docs/operations/imweb/uau-founding-1year.png`

이미지 원본은 `docs/operations/imweb/cover.html`이고, `node docs/operations/imweb/render.mjs`로 다시 만들 수 있습니다.

## 1. U.A.U 멤버 1년권

| 항목 | 값 |
| --- | --- |
| 상품명 | U.A.U 멤버 1년권 |
| 판매가 | 59,000원 |
| 재고 | 무제한 |
| 상품 코드 (자동 연동용, 선택) | UAU-MEMBER-1Y |
| 한 줄 소개 | 한 달 약 4,900원, 커피 한 잔 값으로 이름 옆에 블루 크레스트를. 자동 결제 없는 1년권입니다. |
| 검색 키워드 | U.A.U, 멤버십, 작가 멤버십, 언프레임, UNFRAME |

### 상세 설명

**U.A.U 멤버 1년권**

U.A.U 인증 작가를 위한 1년 멤버십입니다. 결제는 한 번이고, 자동으로 다시 결제되지 않습니다.

**지금 바로 켜지는 혜택**

- 작가 페이지와 작가 목록의 이름 옆 블루 멤버 크레스트
- 홈 화면 멤버 스포트라이트 노출 (오전 10시·오후 6시, 멤버 모두에게 같은 횟수로 돌아갑니다)
- 끊기지 않고 갱신하면 가입할 때의 가격 유지

**준비 중인 혜택** (열리는 대로 추가 비용 없이 켜집니다)

- 조회수·문의·저장 통계
- 워터마크 없는 포트폴리오 PDF
- 큐레이터 브리프·오픈콜 우선 알림

**구매 전에 확인해 주세요**

1. U.A.U 인증 작가로 승인된 분만 이용할 수 있습니다. 인증은 무료이며 u.a.u 사이트에서 신청합니다.
2. 주문서에 **U.A.U 가입 이메일**을 정확히 적어 주세요. 이 이메일로 작가 페이지를 찾습니다.
3. 결제 확인 후 12시간 이내에 크레스트와 스포트라이트가 켜집니다. 1년이 지나면 저절로 꺼집니다.
4. 실물 배송은 없습니다.

심사와 승인은 돈으로 살 수 없습니다. 멤버든 아니든 모든 작가는 같은 기준으로 인증됩니다.

## 2. U.A.U 창립 멤버 1년권

| 항목 | 값 |
| --- | --- |
| 상품명 | U.A.U 창립 멤버 1년권 (선착순 100명) |
| 판매가 | 35,000원 |
| 재고 | **100개** (다 팔리면 아임웹이 품절로 막아 줍니다. 재입고하지 않습니다) |
| 상품 코드 (자동 연동용, 선택) | UAU-FOUNDING-1Y |
| 한 줄 소개 | 창립 멤버 100명만, 연 35,000원. 먹색 크레스트과 함께 이어서 갱신하는 동안 이 가격 그대로. |
| 검색 키워드 | U.A.U, 창립 멤버, 멤버십, 언프레임, UNFRAME |

### 상세 설명

**U.A.U 창립 멤버 1년권 · 선착순 100명**

U.A.U가 시작하는 시기를 함께하는 작가 100명을 위한 멤버십입니다. 결제는 한 번이고, 자동으로 다시 결제되지 않습니다.

**창립 멤버에게**

- 멤버 혜택 전부
- 이름 옆 먹색 창립 크레스트
- 끊기지 않고 갱신하는 동안 연 35,000원 유지
- 연말 Recap 창립 멤버 수록 (준비 중)

**지금 바로 켜지는 혜택**

- 작가 페이지와 작가 목록의 이름 옆 창립 크레스트
- 홈 화면 멤버 스포트라이트 노출 (오전 10시·오후 6시)

**준비 중인 혜택** (열리는 대로 추가 비용 없이 켜집니다)

- 조회수·문의·저장 통계
- 워터마크 없는 포트폴리오 PDF
- 큐레이터 브리프·오픈콜 우선 알림

**구매 전에 확인해 주세요**

1. U.A.U 인증 작가로 승인된 분만 이용할 수 있습니다. 인증은 무료이며 u.a.u 사이트에서 신청합니다.
2. 주문서에 **U.A.U 가입 이메일**을 정확히 적어 주세요.
3. 100명이 차면 창립 멤버는 다시 열리지 않습니다. 이후에는 멤버 1년권(연 59,000원)으로 가입할 수 있습니다.
4. 갱신하지 않고 1년이 지나면 창립 크레스트와 가격이 함께 끝납니다.
5. 실물 배송은 없습니다.

작가 번호에 붙는 무료 '창립 작가' 표시와는 다릅니다. 먹색 크레스트은 유료 창립 멤버에게만 붙습니다.

## 올리기 전에 정할 것

- **환불 정책**: 상세 설명 맨 아래에 스토어 환불 정책을 붙여 주세요. 디지털 상품은 크레스트를 켜기 전과 후로 나눠 안내하는 경우가 많습니다. 정책 문구는 직접 확정해 주세요.
- **"결제 확인 후 12시간 이내"**: 상세 이미지에 이렇게 약속합니다. 사이트 멤버십 FAQ는 아직 "보통 영업일 하루 안에"라고 적혀 있어 맞춰야 합니다. 자동 연동 전까지는 직접 반영해야 합니다.
- **상품 주소**: 멤버 상품 주소를 Netlify 환경변수 `NEXT_PUBLIC_IMWEB_MEMBERSHIP_URL`에 넣으면 사이트의 결제 버튼이 켜집니다. 창립 상품 주소용 변수는 자동 연동 작업 때 함께 추가합니다.

## 상품정보제공고시 (상품군: 디지털 콘텐츠)

| 항목 | 입력 |
| --- | --- |
| 제작자또는공급자 | UNFRAME (사업자등록증의 상호와 같게) |
| 이용조건및이용시간 | U.A.U 인증 작가 전용. 크레스트 적용일부터 365일. 자동 결제 없음 |
| 상품제공방식 | 온라인 제공. U.A.U 사이트의 작가 페이지에 멤버 크레스트와 혜택이 적용됩니다. 파일 다운로드와 배송은 없습니다 |
| 최소시스템사양 | PC·모바일 인터넷 브라우저. 별도 프로그램 설치 없음 |

| 소비자상담관련전화번호 | 사업자 대표 번호 |
