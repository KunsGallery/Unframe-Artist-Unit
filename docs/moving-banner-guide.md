# 흐르는 문구 사용 안내

## 편집 화면

- 메인: `/admin/editor` → 홈 → 흐르는 문구.
- 작가: `/dashboard/profile` → 페이지 구성 → 흐르는 문구. 관리자 대리 편집에서도 동일합니다.
- 관리자 갤러리·프로젝트·오픈콜: `/admin/organizations`.
- 승인된 갤러리·큐레이터·디렉터·기관: 대시보드의 ‘갤러리 · 프로젝트 · 오픈콜’ → `/dashboard/organizations`. 본인 소유 기록만 관리합니다.

## 설정 순서

1. ‘흐르는 배너 표시하기’를 켭니다. 기존 페이지는 기본 꺼짐입니다.
2. 위치를 선택합니다: 히어로 아래 / 소개 아래 / 목록 아래 / 문의 위·하단.
3. 한국어·영어 문구를 각각 입력합니다. 현재 언어의 문구가 비어 있으면 그 언어에서는 배너가 표시되지 않습니다.
4. 필요한 경우 바로가기 링크를 입력합니다. 외부 http(s) 링크는 새 창, `/`로 시작하는 내부 링크는 같은 창에서 이동합니다.
5. 속도·방향을 설정하고 미리보기를 확인합니다.
6. 기존 페이지 저장 버튼을 눌러 반영합니다. 메인 에디터는 발행 버튼을 사용합니다.

작가 페이지는 세 디자인 모두 지원하며, 선택한 섹션이 없는 경우 문의 앞·하단에 표시합니다. 갤러리에서는 ‘전시 목록 아래’, 프로젝트·오픈콜에서는 ‘참여자 목록 아래’를 선택할 수 있습니다.

프로젝트·오픈콜은 갤러리 관리의 전시 레코드에 페이지 유형을 설정해 만드는 공개 상세 페이지입니다. 신청서 접수·심사·자동 마감 기능이 새로 구현된 것은 아닙니다. 배너 링크를 외부 신청서로 연결할 수 있습니다.

방문자는 일시정지할 수 있습니다. 모션 줄이기 설정에서는 반복 애니메이션 대신 정적 문구가 표시됩니다.

## 검증 기록 — 2026-10-04

- 배너 설정·렌더링·위치 선택·링크 안전성 및 기존 데이터 테스트: 7개 통과.
- 로컬 Firestore 에뮬레이터 권한 테스트: 8개. 작가 배너 저장, 승인된 운영자의 소유 기록 저장, 타인의 수정 차단, 소유자 변경 차단 포함.
- Firestore 운영 규칙 배포 성공.
- 실제 계정의 입력·저장·재접속 및 새 상세 배너의 모바일 브라우저 검증은 로그인 후 별도로 확인해야 합니다. 운영 데이터에는 테스트 배너를 등록하지 않았습니다.

이번 변경은 기존 디자인을 유지하는 확장입니다. Impeccable 지침에 따라 공통 설정 폼과 위치 선택, 빈 상태, 모션 줄이기, 링크 안전성을 점검했습니다. 별도 리뷰 에이전트 대신 작업 내 검토를 수행했으며, 기존 디자인 문서는 변경하지 않았습니다.
