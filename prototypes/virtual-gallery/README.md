# U.A.U 가상 전시장 — 로컬 시제품

운영 사이트와 분리된 2룸 3D 전시장 테스트입니다. 한미라 및 작품 6점은 **가상 샘플**이며, 저장·배포·실제 계정 연동은 없습니다.

로컬 주소: `http://127.0.0.1:4173/` (개발 서버가 실행 중일 때)

## 체험할 수 있는 것

- 전시실 2개와 지도·앞뒤 이동 버튼·좌우/상하 드래그 시점 전환
- 광천장 / 일반 천장 / 유리천장
- 기본 전체 조명 / 선택형 작품 집중 조명
- 공유 6000 K 색온도 프리셋과 고정 스포트라이트 배치(작품별 베이킹 없음)
- 작품 벽면용 중간 해상도 JPEG 6장(총 약 1.4 MB), 클릭 시에만 PNG 원본 로드
- 방문자 화면 전환, 모바일 설정 패널, 작품 목록을 통한 키보드 접근
- 고정 전시실에 적용한 벽 미장·밝은 미장 콘크리트 바닥·광천장 확산판 텍스처
- 유리천장 모드의 하늘·구름과 고정 햇빛/창틀 그림자(작가별 조명 베이킹 없음)
- 첫 방문에 한 번 표시되는 조작 안내와 ? 버튼으로 다시 여는 도움말
- 기기별 첫 방문에 전시 포스터·작가·장소·기간·소개를 먼저 보여주는 전시 소개 카드(상단 전시 정보 버튼으로 다시 열기)
- 브라우저 안에서 전시명·작가·장소·기간·소개·포스터 편집
- 작품 편집기: 최대 9점의 이미지·YouTube 영상과 최대 4개의 GLB 오브제를 두 방의 라벨이 붙은 자리로 배치
- 업로드 이미지는 IndexedDB에 원본을 보관하고 최대 1400px WebP 미리보기를 생성해 평소에는 가볍게 표시; 원본은 작품을 열 때만 읽기
- 작품 메타데이터는 localStorage, 바이너리 파일은 IndexedDB를 사용하며 다른 기기·관람객과 동기화되지 않음

바닥을 클릭하면 클릭한 위치로 이동합니다. 다른 방의 바닥을 클릭하면 출입구를 경유합니다. W/S 또는 화면의 앞뒤 버튼은 현재 바라보는 방향을 기준으로 움직입니다. A/D와 좌우 화살표는 각각 왼쪽/오른쪽을 봅니다. 시선의 상하 각도는 과도하게 꺾이지 않도록 제한했습니다. 조작 안내는 ? 버튼으로, 전시 소개는 상단 전시 정보 버튼으로 다시 열 수 있습니다.

## 실행 및 검증

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4173
npm run build
npm run test:sites
```

샘플 작품과 전시 정보는 `src/gallery-model.js`, 전시장 장면과 조명은 `src/GalleryScene.jsx`, 화면과 편집기는 `src/App.jsx`, 브라우저 내 파일 보관은 `src/gallery-storage.js`에 있습니다. 이 편집기는 시제품 범위로, 현재 브라우저 프로필에만 저장됩니다. 실서비스에서 여러 기기와 관람객에게 공유하려면 인증·권한, 서버 측 이미지 변환/CDN, 저장 정책, 갤러리별 데이터/API가 필요합니다. 파일 업로드는 이미지 50MB, GLB 단일 파일 25MB, 포스터 20MB로 제한합니다. 3D 포맷은 GLB만 받고, YouTube 링크는 지원 도메인과 영상 ID를 검증합니다.

## 공간 마감 에셋

ImageGen 기본 도구로 각각 생성한 평면 재질 샘플을 WebP로 압축해 `public/textures/`에 저장했습니다. 실제 화면에서 사용하는 파일은 `wall-plaster.webp`(따뜻한 아이보리 미장 벽), `floor-microcement-v2.webp`(밝고 결이 큰 매끈한 콘크리트), `ceiling-diffuser.webp`(오팔색 광천장 확산판)입니다. 세 파일 합계는 약 61 KB입니다. 미러 반복으로 양쪽 공간에 공유되며, 작가별로 텍스처나 조명을 다시 굽지 않습니다. 첫 바닥 시안 `floor-microcement.webp`는 비교용으로 남겨 두었지만 화면에서는 사용하지 않습니다.

생성 프롬프트 방향: 정면/상단 직교 시점, 균일한 확산광, 그림자·오브젝트·글자 없는 반복 가능한 미세 재질. 벽은 거의 흰색의 낮은 대비 미장, 바닥은 중성 회백색의 넓고 부드러운 미장 결, 천장은 무광 오팔 확산판을 요청했습니다.

조명 색은 sRGB 기반의 6000 K 근사치입니다. 디스플레이 색 관리와 작품 이미지의 색 정확도는 실제 적용 전 별도 보정이 필요합니다.

유리천장의 하늘 자산 `glass-sky.webp`는 ImageGen 기본 도구로 생성한 86 KB WebP입니다. 프롬프트: “맑은 푸른 낮 하늘과 자연스러운 흰 뭉게구름, 바로 위를 올려다본 구도, 수평선·건물·창틀·문자 없음, 사실적인 6000 K 주광.” 실제 태양 위치 계산이나 날씨 연동은 하지 않으며 한 개의 고정 방향광과 그림자 맵을 두 방에서 공유합니다.
